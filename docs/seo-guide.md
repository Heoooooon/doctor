## 2. 페이지별 SEO 설정

### 메인 페이지 (`/`)
```
title: 수원치과 서울이건치과 | 자연치아 보존·임플란트·교정
description: 수원시 영통구 매탄동 서울이건치과. 자연치아 보존을 우선으로 임플란트·교정·소아진료를 안내합니다.
             서울대 출신 대표원장, 원내 기공소, 진료시간·주차·오시는 길을 확인하세요.
canonical: https://egundc.com
```

아래 진료별 문구는 방향 예시이며 현재 출력값의 검수 기록이 아니다.
진료 페이지는 해당 주제를 설명하고, 모든 글의 제목을 `수원치과`로 통일하지 않는다.
키워드 나열이나 지역명을 바꾼 중복 페이지 양산 대신 실제 진료·위치 정보를 제공한다.

### 임플란트 게시판 (`/implant`)
```
title: 수원 임플란트 | 서울이건치과 - 올온4·즉시로딩·네비게이션
description: 서울대 출신 원장이 직접 집도하는 수원 임플란트.
             올온4, 즉시로딩, 네비게이션 가이드 임플란트 전문
```

### 교정 게시판 (`/orthodontic`)
```
title: 수원 교정치과 | 서울이건치과 - 인비절라인 투명교정
description: 교정과 전문의 유수현 원장의 인비절라인 투명교정, 소아 성장기 교정
```

### 소아치과 (`/pediatric`)
```
title: 소아진료 | 서울이건치과
description: 아이의 치아 관리와 치료 상담을 안내합니다. 담당 의료진과 진료시간을 확인하세요.
```

### 원장칼럼 (`/column/[id]`)

- 목록 초기 HTML에서 공개 칼럼의 상세 주소를 일반 `<a href>`로 제공한다.
- 글마다 실제 제목·본문 요약·자기 canonical·article OG·대표 이미지를 제공한다.
- `BlogPosting`은 화면에 있는 정보와 일치시킨다. 작성자·수정일을 추정하거나 생성 시각으로 대체하지 않는다.
- 초안은 공개 목록·사이트맵에서 제외하며 관리자 미리보기도 noindex로 처리한다.

## 4. 기술 SEO 체크리스트

### 필수
- [ ] `next/metadata` API로 각 페이지 title/description 설정
- [ ] `robots.txt` — 관리자 경로 (`/admin`) 차단
- [ ] `sitemap.xml` — 공개 정규 페이지와 공개 칼럼 상세 주소 포함
- [ ] OG 이미지 (`og:image`) — 각 게시판별 1200×630px
- [ ] 각 독립 페이지에 자기 canonical 설정
- [ ] 칼럼 발행·수정·비공개 전환에 목록과 사이트맵 연동

### 권장
- [ ] 정보성 이미지에 실제 내용과 역할을 설명하는 alt 제공; 장식은 `alt=""` 유지
- [ ] 구조화 데이터 (Dentist 타입) 메인 페이지 적용
- [ ] Core Web Vitals — 실사용 75백분위 LCP 2.5초 이하, INP 200ms 이하, CLS 0.1 이하
- [ ] 모바일 브라우저에서 본문·링크·전화·상담 이용 확인

### 이미지 alt 검수

- 이미지 자체와 주변 본문을 함께 보고 작성한다. 파일명만 보고 장면·의료진·장비를 추정하지 않는다.
- 의료진 사진은 인물을, 도표는 주제와 핵심 정보를, 이미지 링크는 이동 목적을 설명한다.
- `수원치과` 등 키워드는 이미지 의미와 맞는 경우에만 자연스럽게 사용한다. 같은 검색어를 모든 이미지에 반복 삽입하지 않는다.
- 진료시간 등 숫자·요일이 있는 이미지와 alt는 실제 운영 정보와 대조한다. 오래된 이미지의 내용을 alt로만 덮어쓰지 않는다.
- 긴 치료 설명은 읽을 수 있는 HTML 본문으로 제공한다. alt를 본문 저장 공간으로 쓰지 않는다.
- 근거: https://developers.google.com/search/docs/appearance/google-images#use-descriptive-filenames-titles-and-alt-text

- 치료 설명 글: 환자 관점, 쉬운 용어 우선 / 전문 용어는 괄호 안에 병기

- 내부 링크: 게시판 간 연관 치료 링크 연결 (임플란트 ↔ 올온4 등)

## 7. Google 성과 측정

- Search Console에서 속성 `egundc.com`, 검색 유형 웹, 검색어 `수원치과`, 국가 대한민국을 기준으로 노출·클릭·CTR·평균 게재순위를 기록한다.
- 페이지별 결과에서 홈페이지와 다른 페이지를 구분하고, 모바일·데스크톱도 나눠 본다. 평균 게재순위 1과 모든 사용자에게 항상 첫 번째로 보이는 것은 다르다.
- 변경 전후 28일을 비교하되, 새로 반영된 페이지는 재수집·색인 날짜를 함께 기록한다.
- URL 검사에서 Google이 선택한 canonical과 색인 여부를 확인한다.
- 지도·이미지·광고·AI 답변의 노출은 일반 웹검색 순위와 별도 지표로 관리한다.
- Search Console 접근과 운영 배포 후 측정이 없으면 실제 1위 달성으로 보고하지 않는다.
